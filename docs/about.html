Bing 每日壁纸自动归档与展示系统

项目简介

本项目是一个完全开源、基于 GitHub Actions 自动构建的必应每日壁纸归档系统。通过自动化脚本，每天定时抓取必应官方超清壁纸（最高支持 4K UHD），并将其整理为 JSON 数据和静态网页进行永久存储。

项目旨在为用户提供一个纯净、无广告、高颜值的壁纸浏览与下载平台。无论您是需要寻找设计灵感，还是想要美化您的桌面，这里都能满足您的需求。

核心特性

🚀 全自动化

基于 GitHub Actions 实现每日定时抓取，无需人工干预，数据自动更新与部署。

🖼️ 高清原图

提供最高 4K UHD 原图下载，同时支持 1080P 及多种分辨率自适应，满足不同设备需求。

📱 完美响应式

PC 端与移动端极致适配，沉浸式全屏轮播与优雅的瀑布流网格布局。

⚡ 极速加载

前端实现图片懒加载、并发控制与断点重试机制，配合 CDN 加速，浏览体验丝滑顺畅。

技术架构

项目前端采用原生 HTML/CSS/JavaScript 构建，无重型框架依赖，追求极致的加载速度与轻量化。数据源与页面展示分离，支持极其便捷的二次开发。

GitHub Actions Node.js 脚本 静态 JSON 数据 Vanilla JS CSS3 动画与毛玻璃 响应式布局
